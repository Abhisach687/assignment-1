## Git & Github, Numpy and Pandas Assignment 

The repository consists of following directories

`/answers`
This directory consists of Git/Github theory, Numpy and Pandas assignment solutions \

`/data`
This directory consits of the code to seed/generate data for the python assignment along with the generated data \

`/outputs`
This directory consists of csv summary output generated during pandas assignment

### To run do the following:

1. Clone the repo:
In your terminal type `git clone https://github.com/Abhisach687/assignment-1.git`

2. Go to assignment-1 directory
`cd assignment-1`

3. Create a virtual venv enviorment
`python -m venv venv`

4. Install the requirements
`pip install -r requirements.txt`

## Navigate the answers 
Go to answers directory to view the answers. `01_git_theory.md` consits of written answers. \
`02_numpy.ipynb` and `03_pandas.ipynb` consist of runnable notebook cells. \
\
If you are using VS-Code then, \
For instance, `code answers/02_numpy.ipynb` will open jupyter notebook for that assignment. You can run each cell after that. \
Similarly, `code answers/03_pandas.ipynb` will open jupyter notebook for that assignment. \

Feel free to reach out if something doesn't work.
